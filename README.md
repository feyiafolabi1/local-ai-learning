# Local AI Learning Lab

Hands-on projects exploring local large language models and AI systems.

## Projects

### 01 — Local Model Benchmarking
Benchmarks multiple local Ollama models across technical reasoning, math, coding, JSON extraction, summarization, and generation speed.

### 02 — Grounding
Demonstrates how to provide trusted source text to a local model and require answers based only on that source.

### 03 — Basic RAG
Implements a retrieval-augmented generation pipeline using:

- Ollama
- EmbeddingGemma
- NumPy
- cosine similarity
- local text documents
- retrieval evaluation
- end-to-end RAG evaluation
